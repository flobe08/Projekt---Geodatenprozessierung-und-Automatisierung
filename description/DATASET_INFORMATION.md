Datensatz: ALKIS Verwaltungsgebiet Bayern  
Link: https://geodaten.bayern.de/odd/m/4/verwaltung/alkis-verwaltung.zip  
Stand: monatlich aktualisiert  
Lizenz: Creative Commons Namensnennung 4.0 International (CC BY 4.0), Bayerische Vermessungsverwaltung / LDBV. Quelle angeben.

### Landnutzung Bayern

Lizenz: Creative Commons Namensnennung 4.0 International (CC BY 4.0), Bayerische Vermessungsverwaltung / LDBV. Quelle angeben.

Lizenz: Open Data Commons Open Database License 1.0 (ODbL). Quelle: OpenStreetMap contributors.
